# 👋 My Profile – Portfolio & Services Website

A modern, responsive personal website built with **Next.js** that presents
my profile, the services I offer, and a showcase of my past work.

## ✨ What's Inside
- **About** – A quick introduction to who I am and what I do
- **Services** – The services I provide and how I can help clients
- **Works / Projects** – A curated selection of my completed projects
- **Contact** – An easy way to get in touch

## 🛠 Tech Stack
- Next.js
- React
- Tailwind CSS (or your preferred styling)
- Deployed on Vercel

## 🚀 Getting Started
npm install
npm run dev

Open http://localhost:3000 in your browser.
